## 📅 Управляющие скрипты (Python)

В каталоге `_actions/` сосредоточена логика валидации отчетов и автоматического исправления базы данных расписания.

### Структура папки

```text
[techlab-journal-attendance]
└── _actions/
    ├── journal-analyzer.py          # Проверка комплектности отчетов
    ├── journal-notify.py            # Диспетчер буферного шлюза
    └── journal_repair/ 
        ├── ja_repair_day.py         # Нормализация дней недели
        ├── ja_repair_delete.py      # Удаление учеников из базы
        ├── ja_repair_fields.py      # Очистка текстовых полей
        ├── ja_repair_modify.py      # Изменение времени групп
        ├── ja_repair_space.py       # Удаление лишних пробелов
        ├── ja_repair_structure.py   # Контроль геометрии YAML
        ├── ja_repair_time.py        # Форматирование синтаксиса времени
        ├── ja_session_manager.py    # Контроль сессий и статусов
        └── journal_repair.py        # Главный диспетчер исправления
```

### Основные диспетчеры шлюза отчетов

*   **`journal-analyzer.py` (Модуль проверки комплектности отчетов)**
    *   **Назначение:** Проверяет, все ли группы преподавателя за конкретную дату прислали отчеты.
    *   **Логика работы:** Сопоставляет количество JSON-файлов в `_input/` со структурой занятий в YAML-расписании. Как только собран полный день, останавливает поиск и переносит всю группу файлов в папку `_output/`.

*   **`journal-notify.py` (Модуль диспетчера буферного шлюза отчетов)**
    *   **Назначение:** Обеспечивает безопасную передачу данных между двумя репозиториями.
    *   **Логика работы:** Работает в непрерывном цикле. Он вызывает анализатор, отправляет коммит с готовым комплектом в сеть, отправляет веб-сигнал на основной сайт через GitHub API и ожидает очистки шлюза `_output` со стороны внешнего сайта.

### Центральный диспетчер автоматического исправления

*   **`journal_repair.py` (Главный диспетчер исправления)**
    *   **Назначение:** Управляет последовательным конвейером очистки и модификации файлов расписания.
    *   **Логика работы:** Проверяет входящий JSON-сигнал, поочередно пропускает целевой YAML-файл через подмодули нормализации текста (`space`, `day`, `time`, `fields`), исправляет геометрию отступов через `structure`, а затем выполняет прямые команды удаления (`delete`) или изменения времени (`modify`).

### Линейные подмодули конвейера исправления

*   **`ja_repair_day.py` (Модуль нормализации названий дней недели)**
    *   **Логика работы:** Выполняет построчный поиск названий дней на корневом отступе. Использует внутренний словарь синонимов и опечаток для приведения строк строго к эталонному виду (например, `пн` или `понеделнник` преобразуются в `понедельник:`).

*   **`ja_repair_space.py` (Модуль удаления лишних пробелов)**
    *   **Логика работы:** Сканирует пары «ключ-значение» в YAML. Полностью удаляет пробелы внутри системного поля `tag`. Во всех остальных текстовых полях схлопывает множественные пробелы (два и более) в один, сохраняя кавычки и комментарии.

*   **`ja_repair_time.py` (Модуль форматирования синтаксиса времени)**
    *   **Логика работы:** Находит строки времени групп и приводит любые ломаные разделители (точки, пробелы, косые черты) строго к формату `ЧЧ:ММ`. Автоматически дополняет недостающие нули (например, `9 15` или `09.15` превращаются в `09:15`).

*   **`ja_repair_fields.py` (Модуль очистки текстовых полей учащихся)**
    *   **Логика работы:** Фильтрует имена, теги и направления от мусора и запрещенных символов. Автоматически распознает сокращения курсов (например, преобразует одиночные буквы `э` или `с` в полные названия `"электронное конструирование"` и `"столярное дело"`) и упаковывает их в JSON-формат.

*   **`ja_repair_structure.py` (Модуль контроля геометрии YAML)**
    *   **Логика работы:** Выравнивает структуру отступов по жесткому белому списку расписания. Принудительно выставляет отступы: 0 пробелов для дней недели, 2 пробела для времени групп, 4 пробела для имен учащихся и 6 пробелов для их параметров (`direction` и `tag`).

### Подмодули выполнения команд модификации

*   **`ja_repair_delete.py` (Модуль удаления учеников)**
    *   **Логика работы:** Ищет точные координаты учебного дня и времени группы в расписании. Находит указанных в сигнале учеников и полностью вырезает их блоки строк вместе со всеми вложенными параметрами.

*   **`ja_repair_modify.py` (Модуль изменения структуры времени группы)**
    *   **Логика работы:** Изолирует границы конкретного дня недели в YAML-файле. Находит строчку со старым временем группы и заменяет её на новое целевое время, сохраняя всю структуру вложенных учеников.

### Системный подмодуль управления состояниями

*   **`ja_session_manager.py` (Модуль контроля сессий и статусов)**
    *   **Логика работы:** Отвечает за логирование и взаимодействие с интерфейсом сайта. Запрашивает у Git Unix-время последних коммитов файлов для исключения конфликтов версий. Записывает текущие фазы работы и детали ошибок в персональные JSON-файлы статусов преподавателей.
