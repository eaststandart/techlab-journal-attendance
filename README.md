# 📂 Основная структура Журнала посещений







## Репозиторий `techlab-journal-attendance`

Представлены папки и файлы для Формирования Журнала посещений на стороне приватного репозитория `techlab-journal-attendance`. Описать зачем создавался репозиторий - доступ дать только преподавателям к его редактированию, чтобы они не смогли редактировать основной репозиторий! Приватный потому что только преподаватели могут редактировать свои файлы расписания а не каждый желающий - поэтому и приватный.













## Репозиторий `eaststandart.github.io`

Представлены папки и файлы для Формирования Журнала посещений на стороне репозитория `eaststandart.github.io`.

### CSS стили оформления страницы отметки в Журнале посещений

В данном каталоге сосредоточено графическое оформление и каскадные таблицы стилей (CSS) сайта Лаборатории. Файлы разбиты на изолированные модули, которые задают дизайн инженерной темы, управляют геометрией карточек и обеспечивают адаптивную верстку страниц под любые экраны.

#### Структура папки css

```text
[eaststandart.github.io]
└── assets/ 
    └── css/ 
        └── journal-attendance.css # Стили веб-страницы журнала посещений.
   
```

#### Список стилей

*   **`journal-attendance.css`** — Оформление интерфейса авторизации, календарной сетки и списков групп.

### Java скрипты

В данном каталоге сосредоточена клиентская логика сайта Лаборатории. Все модули написаны на чистом JavaScript (JS) без тяжелых внешних зависимостей для обеспечения максимальной скорости загрузки страниц.

#### Структура папки

```text
[eaststandart.github.io]
└── assets/ 
    └── js/ 
        └── journal-attendance/ 
            ├── 01-core-auth.js                # Настройки и авторизация.
            ├── 02-students-loader.js          # Загрузка расписания.
            ├── 03-yaml-parser.js              # Разбор и проверка YAML.
            ├── 04-journal-ui.js               # Отображение дней и групп.
            ├── 05-attendance-commands.js      # Посещаемость и команды /d, /r, /m.
            ├── 06-status-and-repair.js        # Статусы и ремонт.
            └── 07-validation.js               # Проверка входных данных.
```

#### Список скриптов

*   **`01-core-auth.js`** — Настройки, вход, авторизация и выход. 
*   **`02-students-loader.js`** —  Загрузка расписания. 
*   **`03-yaml-parser.js`** — Разбор и проверка YAML. 
*   **`04-journal-ui.js`** — Отображение дней и групп. 
*   **`05-attendance-commands.js`** — Сохранение посещаемости и обработка команд. 
*   **`06-status-and-repair.js`** — Уведомления, опрос статуса и сигналы ремонта. 
*   **`07-validation.js`** — Валидация строк ввода. 


### Python скрипты

В данном каталоге сосредоточена клиентская логика сайта Лаборатории. Все модули написаны на чистом JavaScript (JS) без тяжелых внешних зависимостей для обеспечения максимальной скорости загрузки страниц.

#### Структура папки

```text
[eaststandart.github.io]
└── _actions/ 
    └── journal_attendance/ 
        ├── ja_data_parser.py                # Сетевой парсер и сборщик сырых данных Журнала.
        ├── ja_gate_closer.py                # Шлюзовой модуль закрытия смены.
        ├── ja_report_builder.py             # Маркдаун-дизайнер и GraphQL-публикатор отчётов Журнала.
        ├── ja_tgbot_notify.py               # Модуль отправки отчетов в каналы и группы Телеграм.
        ├── ja_tgbot_personal.py             # Модуль отправки персональных отчетов в Телеграм.
        └── journal_attendance.py            # Модуль управления сборкой отчета посещений.
```

#### Список скриптов 
 
*   **`ja_data_parser.py`** —  Загрузка JSON, YAML и транзит плоских структур для генератора отчетов.
*   **`ja_gate_closer.py`** — Сетевое обновление YAML базы расписания и удаление отработанных JSON.
*   **`ja_report_builder.py`** — Импорт сырых данных из парсера, сборка таблиц и отправка в Discussions.
*   **`ja_tgbot_notify.py`** — Рассылка уведомлений по каналам и чатам Телеграм со ссылкой на журнал посещений. 
*   **`ja_tgbot_personal.py`** —  Формирование сжатого текста журнала и отправка личных уведомлений в Телеграм. 
*   **`journal_attendance.py`** — Координация работы модулей генерации отчетов и рассылки уведомлений в Телеграм.
