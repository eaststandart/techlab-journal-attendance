# 🗺️ Дорожная карта проекта

В этом документе изложены глобальные цели, крупные вехи и векторы стратегического управления системой «Журнал посещений». Данный план служит ориентиром для преподавателей, соавторов, руководства клуба и внешних команд, отражая долгосрочные направления развития, и обновляется по мере достижения ключевых этапов.

---

### 📅 Ближайшие планы

На текущий учебный год.

#### Оптимизация и ревизия серверного ядра
* [ ] Провести комплексный аудит производительности модулей `journal-notify.yml`, `journal-notify.py` и `journal-analyzer.py`.

#### Расширение интерактивных команд модерации базы
* [ ] Разработать и внедрить новые клиентские JS-команды для динамического добавления учебных дней и временных интервалов в YAML-базу расписания напрямую через текстовое поле веб-страницы Журнала.

#### Модернизация интерфейса
* [ ] **Адаптация макета для мобильных устройств** — оптимизация геометрии таблиц, CSS-стилей и чекбоксов для повышения скорости загрузки и удобства ведения журнала со смартфонов преподавателей.

#### Контроль актуальности базы учащихся (Автоматика чистки)
* [ ] **Контроль длительного отсутствия:** Написать подмодуль для анализа истории посещений. Если ученик отсутствует на занятиях более 2 месяцев подряд, система должна автоматически генерировать оповещение (в Телеграм или отчеты или выделять цветом ученика в отчетах) с рекомендацией удалить его из YAML-базы расписания.

### 🚀 Перспективные цели (2027)

#### Переход на автоматическое обновление ключей доступа
* [ ] Исследовать возможность миграции системы с классических персональных токенов (срок действия которых ограничен 90 днями) на сквозную авторизацию через GitHub App для автоматического продления сессий соавторов.

#### Создание единой панели администратора
* [ ] Разработать изолированную веб-страницу для руководства Клуба, обеспечивающую интерактивный мониторинг статусов ремонта и выгрузку актуального расписания всех преподавателей на одной карте без ручного чтения YAML-файлов.

#### Развитие экосистемы Телеграм-уведомлений
* [ ] **Расширение функций Телеграм-ботов** — модернизация модулей `ja_tgbot_*.py` для поддержки интерактивного меню, персональных запросов статистики и двусторонней связи с родителями (подробнее в [Issue #87](https://github.com/eaststandart/eaststandart.github.io/issues/87)).
* [ ] **Кастомизация шаблонов оповещений** — создание визуального редактора текстовых шаблонов для push-уведомлений в каналы направлений.

### 🔭 Стратегические ориентиры (2028)

#### Аналитический дашборд статистики
* [ ] Разработать подсистему автоматического подсчета и визуализации динамики посещаемости каждого учащегося за месяц, учебный квартал и год.

#### Синхронизация с персональными календарями
* [ ] Интегрировать модуль автоматического экспорта актуальной сетки занятий Клуба в форматы Google Календарь и Apple Calendar для мобильных устройств родителей.
